# Product Cost Intelligence

## Purpose

Product Cost Intelligence stores the true commercial cost of every stocked product.

These values are independent from Shopify.

They represent how The Fabric Vault purchases stock.

# Cost Principles

Costs should always represent replacement cost.

Historical purchase prices should remain available for reporting.

Changing today's supplier cost must not rewrite historical profits.

---

# Commercial Rules

Vault Brain should always calculate:

Current replacement cost

Estimated order cost

Expected revenue

Expected gross profit

Return on capital

Capital efficiency

before recommending purchases.
